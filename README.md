# Wash Bros Website

Static HTML/CSS/JS starter site for Wash Bros.

## Local
Open `index.html`, or run:

```bash
python -m http.server 8000
```

## GitHub Pages
Create a repo, upload these files to the root, then enable GitHub Pages from the `main` branch.
